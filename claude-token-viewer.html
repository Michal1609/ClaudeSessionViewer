Claude Code – analýza tokenů a subagentů

Rozpad spotřeby tokenů (vstup, výstup, cache, kontextové okno) po hlavním běhu a jednotlivých subagentech, včetně odhadu ceny.

Vyber složku projektu Claude Code (např. c:\Users\micha\.claude\projects\d--Data-Michal-Develop-Work-Synapse). Aplikace načte hlavní *.jsonl soubory (sessions) a k nim podsložky <session>/subagents/. Vše probíhá lokálně v prohlížeči, nic se nikam neposílá.
